# TR-Wellness-Regulation-Sim

This repository mirrors TR-Wellness-Regulation-Sim. Development and releases
take place in the main repository:

**https://github.com/gamze-kose/TR-Wellness-Regulation-Sim**

The tool provides a regulatory impact analysis that makes regulatory uncertainty
measurable under Turkey's Wellness Services Regulation (4 July 2026, Official
Gazette 33300). It generates synthetic wellness centres and health tourists,
matches them against rules transcribed from the regulation, and returns a
three-valued outcome: compliant, non-compliant or undefined.

Please direct questions and contributions to the main repository.
